# Daniel’s Mac pilot

Open **WolfGrid Mac Preview** in your Applications folder. This private pilot is separate from the public WolfGrid website and uses an expiring preview access link.

1. Open **System Settings → Privacy & Security → Full Disk Access**, add the installed WolfGrid Mac Preview app, and enable it. Quit and reopen the app. Its **Check Messages access** button verifies access without reading message content.
2. Sign in with your existing WolfGrid account using email/password. This pilot has not validated external Google/Apple sign-in returning to the Mac window. Use **Mac setup** in the toolbar to return to setup after signing in.
3. Select workspace **22**. Daniel Phillippe retains the selected phone and email; those identifiers were removed only from the two duplicate placeholder records you approved.
4. Review the two previously imported private messages on Daniel’s contact record. Sync is initially off. **Sync messages for my CRM contacts** enables ongoing imports across all uniquely matched contacts you own in this workspace, including contacts added later. It is not limited to Daniel.
5. Connect your personal OpenAI API key using **Verify & save** in Mac setup. Enter it in the app, never in this chat. OpenAI API usage is billed to your OpenAI account separately from a ChatGPT subscription.
6. If desired, enable **Allow AI to use my synced messages**. On Daniel’s contact record, try **Summarize**, **Suggest follow-up**, and **Draft reply**. Check the cited sources and edit the draft. Nothing sends the reply.

Turning either consent off stops its corresponding future use. Imported history is retained. Closing the last Mac window or quitting pauses sync; minimization keeps it running.
