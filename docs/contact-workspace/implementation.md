# WolfGrid contact workspace

The Contacts page has a sticky contact profile and follow-up sidebar with a wider communications and history panel. Existing Inbox routes, display and message storage are reused. Message, Call, Email, and Notes open a compact composer on demand. Recent threads below stay mixed and newest-first regardless of the selected action. Text and Gmail threads show only their latest preview. Communication stats cover 30 days; the Hot badge means the most recent recorded text was within seven days. On narrow screens the contact content stacks.

CRM details, notes, tasks, appointments and contact/property links work without a connected communication channel. The app shows only the supported sending tabs for the signed-in contact and workspace. Existing owner permissions remain in effect; assigning a representative is routing metadata and does not transfer record ownership or reveal private communication history. The classic lead record remains available for records outside the private contact workspace and via the full-record link.

Apple Messages uses the existing native bridge and private message archive. Phone and FaceTime calls are matched on the Mac using uniquely owned contact identifiers. Local call history requires Full Disk Access and Apple call history on the device. Call metadata stays local unless the user enables sync for that contact; saved call metadata stays visible after pausing. Call handoff does not establish connection or delivery, and call records never change the lead stage. The web dialer opens an existing focused dialer list only for a configured salesperson.

Gmail sending uses the existing OAuth account, authorization and send ledger. Recent Gmail history is explicitly imported per contact and bounded to 20 one-to-one results in the last 90 days; messages shared with additional recipients are excluded from import. Provider IDs deduplicate imports and group available replies. The download link remains hidden until an official HTTPS URL is configured in `NEXT_PUBLIC_WOLFGRID_MAC_DOWNLOAD_URL`.

Business card sends and qualifying opens use existing event records. Property events and QR scans are attributed to verified campaign-address links. The existing map engagement state remains independent of disposition and lead stage. Follow-up, property, CRM, and communication data remain in their owning systems; the timeline queries them under the current account and workspace.
